Breadth-First Search

Explores the graph level by level, expanding the shallowest node first. Finds the path with the fewest edges.

Queue (FIFO)CompleteFewest edges
⛏️

Depth-First Search

Dives as deep as possible along one branch before backtracking. Uses little memory but is not optimal.

Stack (LIFO)Low memoryNot optimal
💰

Uniform Cost Search

Always expands the node with the lowest total path cost g(n). Finds the cheapest path when edge costs differ.

Priority QueueCost optimalUses edge costs
